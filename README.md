# Examen civique 2026, réponses vérifiées

Les questions officielles de l'examen civique (carte de séjour pluriannuelle,
carte de résident, naturalisation), avec pour chaque réponse la phrase exacte
de la Constitution, de la Déclaration de 1789 ou du code qui la fonde.
